# Repository governance

Owner decision: no license for now. Every PR needs explicit confirmation from **Tsutayaaa**.
The agent must not merge on the owner's behalf without that confirmation.

Desired server settings: require PRs and passing CI, permit merge commits, disable squash/rebase.
These are repository settings, not enforceable by this Markdown file or the workflow alone.
They have not yet been verified/applied by this change. Do not claim branch protection is active.

If a PR is authored by Tsutayaaa, GitHub cannot count Tsutayaaa's own review as an approving
review. Do not configure an impossible mandatory self-review. A distinct authorized author or
reviewer arrangement is needed before requiring Code Owner approval. Until resolved, owner
confirmation is a procedural requirement; it is not represented as an enforced approval rule.
